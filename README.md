# AI-BASED-SMART-IRRIGATION-SYSTEM-USING-WEATHER-PREDICTION
🌱 AI-Based Smart Irrigation System using ESP32 and OpenWeatherMap API. The system monitors soil moisture, temperature, and rain prediction to automatically control a water pump. Includes AUTO and MANUAL modes with a real-time web dashboard at 192.168.4.1. Designed to reduce water usage by up to 40–50% through intelligent decision-making.
